# Harmonizer Bidirectional

Private archive for the six-camera bidirectional Double DiT experiment.

- Trained checkpoint: 1000 optimizer steps, 8 GPUs, 512×288.
- Main and condition streams each use 20 transformer blocks.
- Current inputs and this model’s own quantized generated history are used for inference.
- Complete source, portable entry points, checkpoint checksums and release download instructions are being prepared.
- Original server source and weights are preserved.

The completed run is `/data/juziwei/hlk/whole_data/runs/training_restart_20261024/bidirectional/`.
