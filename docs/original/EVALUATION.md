# 双路 DiT 评估与消融协议

## 固定指标

所有正式比较限定以下九项。核心指标遵循 DiffusionHarmonizer 对象插入和 RealityBridge 协调评估定义，资产指标为项目补充。运行前需把相应论文定义、实现版本和权重对应起来；本方案不把未核查实现标成论文等价。

| 指标 | 方向 | 必须明确的参考与实现 |
| --- | --- | --- |
| FID | 越低越好 | 预测当前图与配对协调 GT 图像集合；同样本、分辨率和 Inception 预处理 |
| FVD | 越低越好 | 自回归输出序列与对应 GT 序列；同序列、时间戳、帧数、分辨率及视频特征模型 |
| DINO structure preservation | 按实现标距离↓或相似度↑ | 论文的输入到输出结构保持定义；不能替换成输出到 GT 的 pooled CLS 相似度后仍称论文同指标 |
| SC | 越高越好 | 核查 Subject Consistency 的特征提取、参考帧和时间聚合规则 |
| TF | 越高越好 | 核查 Temporal Flickering score 的实现与分数变换，不把原始闪烁误差当作高优分数 |
| MS | 越高越好 | 核查 Motion Smoothness 的运动模型、采样与聚合 |
| Asset FID | 越低越好 | 同一监督资产 mask 派生的预测/GT crop 分布，同裁剪和 resize 策略 |
| Asset DINO | 按实现标距离↓或相似度↑ | 项目补充，固定预测 crop 与配对协调 GT crop 的 DINO 比较、层与 pooling 方式 |
| Asset L1 | 越低越好 | 原始对应坐标下，预测与配对协调 GT 在资产 mask 内的 RGB 绝对差，值域 `[0,1]` |

验证和测试不计算、不汇报 PSNR、SSIM、LPIPS，包括资产区域变体，也不新增其他质量指标填补缺项。本次保留官方训练损失所用的 VGG-LPIPS 仅属于训练优化和训练 loss 日志，不属于这里的质量指标；不能直接调用官方脚本附带的验证 LPIPS。耗时、显存、参数量和梯度状态作为工程记录，不冒充质量指标。

如果资产 crop 协议已有经过核查的项目实现，应对所有模型复用同一版本。否则预注册补充协议：资产 union mask 的紧包围框，中心不变地将宽高各扩大 1.1 倍并裁到边界；预测与 GT 使用相同框；Asset FID 使用同一 Inception 预处理，Asset DINO 使用选定 DINO 预处理。mask 不参与生成；crop 中的上下文不会自动被 mask 掉，必须如实记录。空 mask 图不参加资产指标，单列数量与原因。Asset L1 在 resize 前的统一评估分辨率上按 mask 像素归一化，再按有效图平均。

Asset DINO 的 GT 比较是项目补充，不等同于输入到输出的 DINO structure preservation。两者应分别保存比较图像身份和特征定义。

## 样本和时间协议

评估清单需冻结以下内容：

- source、GT、mask、sequence/camera/asset/render 身份及其 hash；划分与排除规则。
- 模型输入分辨率和输出评估分辨率，缩放、padding、裁剪、量化与颜色范围。
- 运行配置中实际自回归协议的历史来源、历史分辨率、首帧比例、补齐比例、恢复日志与重复历史标记；当前实现为 `ar_generated_repeat_oldest_native_rgb_v1`，使用原生分辨率 uint8 往返缓存。
- 每个序列的真实时间戳、间隔、有效相机和几何路由；不得把稀疏采样结果称为原视频连续帧评估。
- 视频窗口长度建议先核查 16 帧是否有足够真实轨迹。短序列不能复制当前帧凑满；若目标实现不支持该长度或有效样本不足，应报告 FVD/SC/TF/MS 缺失及原因。
- 所有模型使用同一输出和 GT 选择集合。比较时若某模型失败，列出失败数量；不能只删除它的难样本后继续比较。

2026-10-21 起，后续训练输入和评估输出均按 `288×512`，即宽 512、高 288；配置均为 `[H,W]`。生成历史反馈也使用该训练尺寸。原第 1000 步 checkpoint 的训练输入为 `576×1024`，历史记录保留，不作为已完成新尺寸训练的证据。正式比较需确认所有样本及资产 mask 的缩放规则；DINO 和 Inception 的内部 resize 另行记录。

历史旧结果即使模型名称相同，也不能直接搬到本方案表格：历史来源、启动方式、输入尺寸和样本集合都可能不同。所有主对照需在新协议下重新自回归生成，记录同一 checkpoint 的实际身份。每个模型使用自己此前生成的输出，不能共享其他模型的历史预测。

## 消融设计

| 版本 | 变化 | 回答的问题 |
| --- | --- | --- |
| 官方单路初始化 | 官方权重，在新自回归协议重跑，不继续训练 | 提供未微调基准 |
| 官方机制单路继续训练 | 同数据/生成历史/主损失/更新预算，主路全量及 VAE 按官方范围训练 | 双路是否超过同训练机制的单路 |
| 单相机条件双路 | 保留完整条件路和双向交互，关闭条件路跨相机边 | 收益来自额外容量还是多视角信息 |
| 单向双路 | M→S 保留，S→M 全关闭 | 主路反馈是否必要 |
| 仅末层交换 | 只有 block 19 的 M→S，其余两路交互关闭 | 中间层交流是否优于末层融合 |
| 推荐完整双路 | 两路 20 层全程联合优化，5 次 M→S，4 次 S→M，官方主损失 | 主方案 |
| 浅条件路 | 8 层条件路，对接主路同五个交换层位 | 20 层条件路是否值得其参数成本 |
| 条件路不池化 | 条件 token 空间不池化 | 小资产信息是否受池化影响 |

浅路可将 8 个块按 `[1,2,2,2,1]` 分配到五个交互阶段；初始化从原 20 层均匀选取，并将索引写进独立配置与架构签名。该变体不是本次默认配置。

所有训练对照保持相同数据顺序、GT 目标、优化步数、有效 batch、历史协议和验证频率，报告参数量与实际 GPU 时间。完整双路与浅路的等步数比较不代表等计算量，若做等计算预算研究要另列。结论阶段尽可能用多随机种子检验稳定性；小样本或单次运行不宣称确定提升。

所有训练消融都保留主路的官方可训练范围、VAE 的 `time_conv` 例外和官方主损失，不在结构消融中偷偷改为冻结主路或只更新末层。报告实际有效相机图像曝光数，不能把多视角 rollout 的更新次数等同于官方原始图像 batch 的数据预算。资产区域附加损失单独作为后续损失消融，默认主方案不启用。

## 报告格式

每个模型保存配置及完整 checkpoint hash、官方训练源码 hash、训练配方签名、可训练参数清单、数据 manifest hash、九项结果、各项状态 `ok/missing/failed`、样本/序列数、参考图定义、crop/mask 规则、时间协议及实现版本。缺失分数用 `null` 和原因表达，不能写 0，也不能使用另一个协议的分数补齐。

当前已完成实现契约检查并进入训练流程，九项正式质量指标尚未运行；训练 loss 和 smoke 检查不是质量评估结果。是否采用完整双路，应根据同协议九项指标和计算开销判断。
