# 双路 DiT 多视角协调方案

以官方 DiffusionHarmonizer 训练机制为基础，保留主路的训练任务和更新范围，增加可联合优化的多视角 DiT 条件分支。主路从官方权重初始化，自第一个优化步起全量训练；条件路通过主路最终损失获得梯度。两路在中间层交换信息，主路负责完整输出。

推荐版本为 `double_dit_v1_full`：两路各 20 层、宽度 1280；多视角路在较低空间 token 分辨率工作；在零基索引 `[3, 7, 11, 15, 19]` 交换信息。前四次双向，最后一次仅由主路读取条件路。视频逐时刻生成，从第二个时刻起使用已生成结果作为历史。

2026-10-21 起，后续训练尺寸按用户要求改为 **512×288（宽×高）**，配置 `data.image_hw=[288,512]`。输入、监督及生成历史反馈均采用该尺寸。现存第 1000 步 checkpoint 来自原 1024×576 训练；对应 `runs/` 记录保留原值，尚未进行新尺寸训练或验证。

本目录现包含双路模型、官方训练损失、数据审计、生成历史训练循环及四卡启动器。运行入口与验证结果见 [RUNNING.md](RUNNING.md)，实时阶段见 `runs/PIPELINE_STATUS.json`，正式训练进度见 `runs/train/STATUS.json`。本轮正式质量指标尚未计算。

两个实施前必须处理的条件：

1. 当前本地分组报告仅确认 1 组完整六视角样本，且只确认源相机同步，不保证生成资产跨视角一致。需要核查可用的 2–5 视角子集和资产版本，不能拼接任意相机图像补齐六视角。
2. 已从官方训练命令及训练调用链确认本地参考版本采用 `timestep=250`、一次 `denoise`、RGB MSE 加截断 VGG-LPIPS，主路全量更新，VAE 按官方规则更新并排除 `time_conv`。这些训练设置有训练代码依据，不是从推理流程推定。

默认取消分支单独预热、主路末五层微调和自定义三项 L1 主损失。新模块保留零门控初始化；资产 L1 等附加监督默认关闭。LPIPS 仅按本次保留官方损失的要求用于训练，评估仍限定九项指标。生成历史、跨视角分组和双路结构属于扩展，因此整个系统称为“基于官方训练机制的双路扩展”，不称为官方原训练的完全复现。

详细来源见 [实现文档中的本地证据](IMPLEMENTATION.md#本地证据)。所有实验须以 `hlk` 运行，并遵守 `/mnt/hlk/AGENTS.md`。
